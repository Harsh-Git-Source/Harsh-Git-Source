# Data

The PPMI Online dataset is not included in this repository.

Place authorized raw CSV files in `data/raw/`. Do not commit private, restricted, or licensed patient-level data.

The project report describes:
- ~890 initial questionnaire columns
- Patient ID + Event ID based merging
- Screening-event filtering
- >50% missingness removal
- 143 final questionnaire features
- 38,256 records
